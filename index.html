Information and Communications Task

ICT Project Results from ITaLab

View Achievements🚀

Wi-Fi Pathloss Modelling

A project focused on BIM based Wi-Fi path loss modeling using building geometry and material properties to determine optimal Wi-Fi access point placement for improved coverage and reduced signal loss.

Rule Checking System

A rule checking system for validating BIM models against high speed information communication compliance requirements for apartment buildings.

Datasets

A curated collection of Revit libraries, sample IFC files for testing, and datasets related to Wi-Fi propagation and signal behavior.
